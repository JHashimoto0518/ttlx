# 要求定義: Go バージョンアップグレード (1.21.13 → 1.25.5)

## 概要

Go のバージョンを現在の 1.21.13 から最新の安定版 1.25.5 にアップグレードする。

## 背景

### 現状の問題

- 現在のバージョン: **Go 1.21.13**
- 最新の安定版: **Go 1.25.5**
- プロジェクト開始日: 2025-12-31
- 当時の最新版は Go 1.23 だったが、1.21 を採用

### なぜアップグレードが必要か

1. **セキュリティリスク**
   - 1.21 リリースから時間が経過し、セキュリティパッチが適用されていない
   - 最新版には複数のセキュリティ修正が含まれる

2. **パフォーマンス向上の機会損失**
   - コンパイラ最適化の改善
   - ランタイムの効率化
   - ビルド時間の短縮

3. **標準ライブラリの改善**
   - バグフィックス
   - 新機能の追加
   - API の改善

4. **エコシステムとの乗り離れ**
   - 最新の開発ツールが 1.25 を前提とする可能性
   - 将来的な依存ライブラリの更新で問題が発生する可能性

## ユーザーストーリー

### 開発者として
- 最新の Go バージョンで開発したい
- セキュリティパッチが適用された環境で開発したい
- 最新のツールサポートを受けたい

### ユーザーとして
- セキュアなバイナリを使用したい
- パフォーマンスが向上したバイナリを使用したい

## 受け入れ条件

### 必須条件

1. **Go バージョンの更新**
   - [ ] `go.mod` の Go バージョンが 1.25.5 になっている
   - [ ] すべての依存ライブラリが Go 1.25.5 で動作する

2. **テストの成功**
   - [ ] 全ユニットテストが成功する
   - [ ] 全統合テストが成功する
   - [ ] テストカバレッジが維持される（97.8% 以上）

3. **ビルドの成功**
   - [ ] `go build` が成功する
   - [ ] golangci-lint が成功する
   - [ ] 生成されるバイナリが正常に動作する

4. **ドキュメントの更新**
   - [ ] README.md の必要要件が更新される
   - [ ] README.en.md の必要要件が更新される
   - [ ] docs/architecture.md の Go バージョンが更新される

5. **開発環境の更新**
   - [ ] devcontainer の Go バージョンが更新される（該当する場合）
   - [ ] CI/CD パイプラインの Go バージョンが更新される（該当する場合）

### オプション条件

- [ ] Go 1.25 の新機能を活用したコード改善（スコープ外）
- [ ] パフォーマンスベンチマークの実施（スコープ外）

## 制約事項

### 技術的制約

1. **後方互換性**
   - Go 1.21 → 1.25 は後方互換性があるため、コード変更は基本的に不要
   - ただし、deprecated な API を使用していないか確認が必要

2. **依存ライブラリ**
   - 現在の依存ライブラリはすべて Go 1.25 に対応している
   - バージョン固定は不要

3. **ビルド環境**
   - ローカル開発環境
   - devcontainer（該当する場合）
   - CI/CD パイプライン（該当する場合）

### 非機能要件

1. **破壊的変更なし**
   - ユーザー向けの API、CLI インターフェースに変更なし
   - 生成される TTL スクリプトに変更なし

2. **ダウンタイムなし**
   - ユーザーは既存のバイナリを使い続けられる
   - 新しいバージョンのリリース後に移行

## スコープ

### スコープ内

- Go バージョンの更新（1.21.13 → 1.25.5）
- テストの実行と成功確認
- ドキュメントの更新
- 開発環境の更新

### スコープ外

- Go 1.25 の新機能を使ったコード改善
- パフォーマンスベンチマーク
- 依存ライブラリのバージョンアップ（Go 1.25 対応のみ）
- 新機能の追加

## リスクと対策

### リスク

1. **互換性問題**
   - **リスク**: Go 1.25 で動作しない可能性
   - **対策**: 全テストの実行、ビルド確認

2. **依存ライブラリの問題**
   - **リスク**: 依存ライブラリが Go 1.25 で動作しない
   - **対策**: 事前確認済み（cobra, testify, yaml.v3 はすべて対応）

3. **開発環境の不整合**
   - **リスク**: ローカル環境と CI/CD で Go バージョンが異なる
   - **対策**: devcontainer, CI/CD も同時に更新

## 成功の定義

1. すべてのテストが成功する
2. ビルドが成功する
3. 生成されるバイナリが正常に動作する
4. ドキュメントが更新される
5. CI/CD パイプラインが成功する（該当する場合）
