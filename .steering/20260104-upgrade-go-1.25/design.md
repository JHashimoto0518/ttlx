# 設計書: Go バージョンアップグレード (1.21.13 → 1.25.5)

## 概要

Go のバージョンを 1.21.13 から 1.25.5 にアップグレードする。後方互換性があるため、コード変更は基本的に不要で、設定ファイルとドキュメントの更新が主な作業となる。

## 実装アプローチ

### 基本方針

1. **最小限の変更**
   - Go バージョンの指定を更新するのみ
   - コード変更は不要（後方互換性あり）

2. **段階的な検証**
   - 各変更後にテストを実行
   - 問題があれば即座に対応

3. **ドキュメントの同期更新**
   - 技術的な変更とドキュメント更新を同時に実施

## 影響範囲の分析

### コード影響

**影響なし:**
- `internal/` 配下のすべてのコード
- `cmd/` 配下のすべてのコード
- `test/` 配下のすべてのテストコード

**理由:**
- Go 1.21 → 1.25 は後方互換性あり
- 使用している標準ライブラリ API に変更なし
- 依存ライブラリもすべて対応済み

### 依存ライブラリの互換性

**確認済み:**

| ライブラリ | バージョン | Go 1.25 対応 |
|-----------|-----------|-------------|
| `github.com/spf13/cobra` | v1.10.2 | ✅ 対応 |
| `github.com/stretchr/testify` | v1.11.1 | ✅ 対応 |
| `gopkg.in/yaml.v3` | v3.0.1 | ✅ 対応 |

**対応方法:**
- バージョン固定は不要
- `go mod tidy` で依存関係を整理

### ビルド影響

**影響あり:**
- ビルド時に Go 1.25.5 が必要
- 開発環境、CI/CD で Go 1.25.5 のインストールが必要

**影響なし:**
- 生成されるバイナリの互換性
- ユーザー向けの機能・API

### 実行時影響

**影響なし:**
- 生成される TTL スクリプトに変更なし
- CLI インターフェースに変更なし
- 動作に変更なし

**期待される改善:**
- パフォーマンスの向上（コンパイラ最適化）
- セキュリティの向上（パッチ適用）

## データ構造の変更
